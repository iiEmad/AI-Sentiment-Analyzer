# 🤖 SentiVision AI

An AI-powered sentiment analysis system built using Natural Language Processing and Transformer models.

## 🚀 Features

- AI sentiment prediction
- Confidence score calculation
- Keyword extraction
- AI-generated explanations
- Sentiment history tracking
- Analytics dashboard
- Responsive web interface


## 🧠 AI Technology

Model:

DistilBERT Sentiment Analysis Model

Frameworks:

- Python
- Flask
- Hugging Face Transformers
- SQLite
- HTML
- CSS
- JavaScript
